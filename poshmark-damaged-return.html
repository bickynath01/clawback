What Do I Lose on a Poshmark Damaged Return?

The refund gets the attention — but on a damaged-item return the real losses are usually the return shipping and the item's lost value once it comes back worse.

What actually happens

Poshmark takes commission on completed sales. When a return is approved and the buyer is refunded, the sale is typically reversed. The part that still hurts you: any return shipping you cover, and the drop in what the item is worth after it returns damaged. Commission details change, so verify the current policy — but shipping and value drop are the numbers that matter.

Worked example

You sold an item for $50. The buyer reports damage, Poshmark approves the return, and the item comes back worth about $20. Even with the sale reversed, you're down the $30 value drop (plus any return shipping you paid). That's the loss most sellers never add up.
