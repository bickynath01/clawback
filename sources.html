Our method, in one line

Loss = fees the platform keeps + return shipping you paid + the drop in the item's value. For eBay, which fees are kept depends on the return reason, so we ask "what happened?" and apply the matching fee-credit rule from eBay's own policy. For the others, approved returns reverse fees, so the loss is dominated by value drop and (for Mercari heavy items) shipping. For Whatnot, the calculator also exposes the "bite ratio" — the real effective fee rate when you include processing on gross order value and carrier clawbacks.

How we stay current

  • Re-verification every quarter (Jan / Apr / Jul / Oct), plus whenever a platform emails a policy change.
  • The footer and this page always show the last-verified date — if it's stale, call us out.
  • Corrections from sellers are treated as bug reports and checked against the official page before we change a number.
