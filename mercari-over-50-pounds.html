Mercari Returns Over 50 lbs: Who Pays the Return Label?

Mercari's prepaid return labels have weight limits. For heavy items, the return shipping can fall on you to arrange and pay — and that's where the real loss hides.

The weight-limit trap

On an approved return, Mercari refunds the buyer and the sale is reversed. But prepaid labels only cover standard weights; very heavy items (over roughly 50 lbs) may not qualify for the same prepaid return, so the shipping cost and logistics can land on the seller. Combined with any drop in the item's value, that's your real exposure.

Details change, so verify the current Mercari policy — but if you sell heavy items, plan for the shipping.

Worked example

You sold a heavy item for $80. The return is approved, and because of its weight you cover $25 in return shipping; the item comes back worth about $50. Loss: $25 shipping + $30 value drop = $55. That's the number to know before you appeal.

FAQ

Does Mercari pay the return label for heavy items?
Prepaid labels have weight limits; over the limit, shipping can fall to the seller.
Do I get the selling fee back?
The sale is reversed, but shipping and value loss often aren't recovered.
How do I protect myself?
Weigh items before listing and factor return shipping into heavy-item pricing.
